## PART 7: CHEAT SHEETS & QUICK REFERENCES

### SQL Quick Reference

```sql
-- SELECT
SELECT column1, column2 FROM table WHERE condition GROUP BY column ORDER BY column;

-- JOIN
SELECT * FROM table1 INNER JOIN table2 ON table1.key = table2.key;

-- CTE
WITH cte AS (SELECT * FROM table) SELECT * FROM cte;

-- Window Functions
SELECT *, ROW_NUMBER() OVER (PARTITION BY group ORDER BY value) FROM table;

-- Aggregates
SELECT COUNT(*), SUM(value), AVG(value), MIN(value), MAX(value) FROM table;

-- Date Functions
SELECT DATE_TRUNC('month', date_column), EXTRACT(YEAR FROM date_column) FROM table;

-- String Functions
SELECT CONCAT(col1, col2), LOWER(col), UPPER(col), LENGTH(col) FROM table;

-- NULL Handling
SELECT COALESCE(column, default_value), NULLIF(column, '') FROM table;
```

### SHAP Quick Reference

```python
# Tree-based models
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X)

# Any model
explainer = shap.KernelExplainer(predict_fn, background)
shap_values = explainer.shap_values(X, nsamples=100)

# Plots
shap.summary_plot(shap_values, X, feature_names=features)
shap.bar_plot(shap_values, feature_names=features)
shap.waterfall_plot(shap.Explanation(
    values=shap_values[0],
    base_values=explainer.expected_value,
    data=X.iloc[0],
    feature_names=features
))

# Feature Importance
importance = np.abs(shap_values).mean(axis=0)
ranked = sorted(zip(features, importance), key=lambda x: x[1], reverse=True)
```

### Fairlearn Quick Reference

```python
from fairlearn.metrics import (
    demographic_parity_difference,
    equalized_odds_difference
)

# Calculate fairness metrics
dp_diff = demographic_parity_difference(y_true, y_pred, sensitive_features=groups)
eo_diff = equalized_odds_difference(y_true, y_pred, sensitive_features=groups)

# Thresholds
# dp_diff < 0.10   = Acceptable
# eo_diff < 0.10   = Acceptable

# Mitigation
from fairlearn.reductions import ExponentiatedGradient, DemographicParity

mitigator = ExponentiatedGradient(
    estimator=model,
    constraints=DemographicParity(),
    eps=0.01
)
mitigator.fit(X_train, y_train)
```

## PART 10: GLOSSARY

### A

**Accuracy:** The proportion of correct predictions among total predictions.

**Anonymization:** The process of removing identifying information from data.

**AUC-ROC:** Area Under the Receiver Operating Characteristic curve; measures model's ability to distinguish between classes.

### B

**Bayes' Theorem:** A probability theorem that describes the probability of an event based on prior knowledge.

**BI (Business Intelligence):** Technologies and strategies for analyzing business data.

**Bias (Statistical):** Systematic error in data or model predictions.

### C

**Causation:** A relationship where one event directly causes another.

**CCPA:** California Consumer Privacy Act; state-level privacy regulation.

**CLV (Customer Lifetime Value):** The total worth of a customer over their entire relationship with a business.

**Correlation:** A statistical relationship between two variables.

**CTE (Common Table Expression):** A temporary result set in SQL.

### D

**Data Mart:** A subset of a data warehouse focused on a specific business line.

**Data Warehouse:** A central repository for integrated data.

**dbt:** Data Build Tool; enables version-controlled SQL transformations.

**Demographic Parity:** A fairness metric requiring equal selection rates across groups.

**Differential Privacy:** A privacy technique that adds noise to protect individual data.

**Docker:** Containerization platform for consistent environments.

### E

**Equalized Odds:** A fairness metric requiring equal error rates across groups.

**Equal Opportunity:** A fairness metric requiring equal true positive rates across groups.

**ETL:** Extract, Transform, Load; data pipeline process.

### F

**Fact Table:** A table containing quantitative data in a data warehouse.

**Fairness:** The absence of unjust bias in model predictions.

**Foreign Key:** A column that references a primary key in another table.

### G

**GDPR:** General Data Protection Regulation; EU privacy regulation.

**Governance:** The framework for managing and protecting data.

**GROUP BY:** SQL clause for grouping data for aggregation.

### H

**HAVING:** SQL clause for filtering grouped data.

**Hypothesis Testing:** Statistical method for making decisions with data.

### I

**Index:** A database structure that speeds up query execution.

**Intermediate Model:** A dbt model that combines staging data.

### J

**JOIN:** SQL operation to combine data from multiple tables.

### K

**Key Performance Indicator (KPI):** A measurable value that demonstrates business performance.

### L

**LIME:** Local Interpretable Model-agnostic Explanations; model explanation technique.

### M

**Mart Model:** A business-ready dbt model optimized for BI.

**Materialized View:** A view that stores data physically.

**Mean:** The average of a set of values.

**Median:** The middle value in an ordered set.

### N

**Normalization:** Database design process to reduce redundancy.

**Null:** A missing or unknown value.

### O

**ORDER BY:** SQL clause for sorting results.

### P

**P-value:** The probability of obtaining results as extreme as observed.

**Primary Key:** A column that uniquely identifies each row.

**Protected Attribute:** A characteristic protected from discrimination (e.g., race, gender).

**Pseudonymization:** Replacing identifiers with tokens.

### Q

**Query:** A request for data from a database.

### R

**R-squared:** The proportion of variance explained by a model.

**Regression:** A statistical method for predicting continuous outcomes.

### S

**SCR Framework:** Situation, Complication, Resolution; storytelling framework.

**Semantic Layer:** Business-friendly abstraction of data.

**SHAP:** SHapley Additive exPlanations; model explanation technique.

**Staging Model:** A dbt model that cleans and prepares raw data.

**Standard Deviation:** A measure of data dispersion.

### T

**Test (dbt):** Data quality validation.

**Type I Error:** False positive.

**Type II Error:** False negative.

### U

**UUID:** Universally Unique Identifier.

### V

**View:** A virtual table based on a query.

### W

**WHERE:** SQL clause for filtering rows.

**Window Function:** SQL function that performs calculations across a set of rows.
