## 1. Official Provider Documentation

### OpenAI
- **OpenAI API Documentation**: [platform.openai.com/docs](https://platform.openai.com/docs) — Complete API reference, guides, and best practices for GPT models, embeddings, and more.
- **OpenAI Cookbook**: [github.com/openai/openai-cookbook](https://github.com/openai/openai-cookbook) — Code examples for structured outputs, tool use, retrieval, evals, and other LLM application patterns .
- **OpenAI Models Overview**: [platform.openai.com/docs/models](https://platform.openai.com/docs/models) — Detailed information on available models, capabilities, and pricing.

### Anthropic
- **Anthropic API Documentation**: [docs.anthropic.com](https://docs.anthropic.com) — Complete API reference for Claude models.
- **Prompt Engineering Guide**: [docs.anthropic.com/claude/docs/prompt-engineering](https://docs.anthropic.com/claude/docs/prompt-engineering) — Techniques for defining success criteria, testing prompts, and improving model behavior .
- **Building Effective Agents**: [anthropic.com/research/building-effective-agents](https://anthropic.com/research/building-effective-agents) — Practical patterns and tradeoffs for agentic systems .
- **Anthropic Research**: [anthropic.com/research](https://anthropic.com/research) — Latest research papers and technical reports.

### Google
- **Google AI Studio**: [ai.google.dev](https://ai.google.dev) — Documentation for Gemini API, including text, vision, and multimodal capabilities.
- **Google Machine Learning Crash Course**: [developers.google.com/machine-learning/crash-course](https://developers.google.com/machine-learning/crash-course) — A compact introduction to supervised ML concepts and applied modeling .
- **Google Agent Development Kit**: [google.dev/agent-development-kit](https://google.dev/agent-development-kit) — Framework for developing and evaluating agents .

### Microsoft
- **Microsoft Learn AI Hub**: [learn.microsoft.com/en-us/training/student-hub](https://learn.microsoft.com/en-us/training/student-hub) — All the tools, training, and community support to assist you build, learn, and succeed with Microsoft AI .
- **Azure AI Documentation**: [learn.microsoft.com/azure/ai-services](https://learn.microsoft.com/azure/ai-services) — Azure AI services, Azure OpenAI, and machine learning documentation.
- **Microsoft AI for Beginners**: [github.com/microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners) — A 12-week program exploring neural networks, deep learning, and hands-on work with TensorFlow and PyTorch .
- **Generative AI for Beginners**: [github.com/microsoft/generative-ai-for-beginners](https://github.com/microsoft/generative-ai-for-beginners) — A 21-lesson course for developing Generative AI apps in Python and TypeScript .
- **AI Agents for Beginners**: [github.com/microsoft/ai-agents-for-beginners](https://github.com/microsoft/ai-agents-for-beginners) — A 10-lesson course covering core concepts in a clear, flexible format .
