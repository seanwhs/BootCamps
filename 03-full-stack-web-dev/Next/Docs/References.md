## Code Examples and Patterns

### Common Code Snippets

**Environment Variable Validation**
```ts
import { z } from "zod";

const schema = z.object({
  DATABASE_URL: z.string().url(),
  APP_URL: z.string().url(),
  LOG_LEVEL: z.enum(["debug", "info", "warn", "error"])
});

const validated = schema.parse(process.env);
```

**Parameterized SQL Query**
```ts
const projects = await database`
  SELECT p.*, COUNT(t.id) as task_count
  FROM projects p
  LEFT JOIN tasks t ON t.project_id = p.id
  WHERE p.owner_id = ${userId}
  GROUP BY p.id
  ORDER BY p.updated_at DESC
`;
```

**Server Action Pattern**
```ts
"use server";

export async function createProjectAction(
  prevState: FormState,
  formData: FormData
): Promise<FormState> {
  const parsed = schema.safeParse({
    name: formData.get("name")
  });
  
  if (!parsed.success) {
    return { status: "error", errors: parsed.error.issues };
  }
  
  const project = await createProject(parsed.data);
  revalidatePath("/projects");
  redirect(`/projects/${project.id}`);
}
```

**Client Component Form**
```tsx
"use client";

export function CreateProjectForm() {
  const [state, action, pending] = useActionState(
    createProjectAction,
    { status: "idle" }
  );
  
  return (
    <form action={action}>
      <input name="name" />
      <button disabled={pending}>
        {pending ? "Creating..." : "Create"}
      </button>
    </form>
  );
}
```

**Protected Route Pattern**
```tsx
import { requireUser } from "@/lib/auth/session";

export default async function WorkspaceLayout({
  children
}: { children: ReactNode }) {
  const user = await requireUser();
  return (
    <div>
      <AccountMenu user={user} />
      {children}
    </div>
  );
}
```

**Owner-Scoped Query**
```ts
export async function getProjectById(userId: string, projectId: string) {
  const rows = await database`
    SELECT * FROM projects
    WHERE id = ${projectId} AND owner_id = ${userId}
    LIMIT 1
  `;
  return rows[0] || null;
}
```

## Glossary of Terms

### Core Concepts

| Term | Definition |
|------|------------|
| **App Router** | Next.js's routing system based on directories and files inside the `app` directory |
| **Server Component** | A React component that renders on the server and doesn't send component code to the browser |
| **Client Component** | A React component that runs in the browser and can use hooks and event handlers |
| **Layout** | Shared UI that wraps multiple pages; persists across navigation |
| **Route Group** | A directory in parentheses that organizes routes without affecting the URL |
| **Route Handler** | An API endpoint defined in a `route.ts` file |
| **Server Action** | A server-side function called from a form or UI element |
| **Hydration** | The process of attaching JavaScript behavior to server-rendered HTML |

### Data and State

| Term | Definition |
|------|------------|
| **Parameterized Query** | A SQL query where values are sent separately from the SQL to prevent injection |
| **Request Memoization** | Deduplicating identical queries during one server render request |
| **Runtime Validation** | Checking data at runtime with Zod or similar libraries |
| **Mutation** | An operation that changes data (create, update, delete) |
| **Revalidation** | Invalidating cached data so it's refreshed on next request |
| **Streaming** | Sending parts of the response as they become ready |

### Authentication

| Term | Definition |
|------|------------|
| **Authentication** | Verifying a user's identity |
| **Authorization** | Determining if a user can perform an action |
| **Session Token** | A random identifier used to maintain a user's session |
| **Password Hash** | A one-way transformation of a password (bcrypt) |
