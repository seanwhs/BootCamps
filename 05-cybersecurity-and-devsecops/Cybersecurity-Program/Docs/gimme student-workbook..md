## 1.1: Welcome & Overview

### Learning Objectives

By the end of this module, you will be able to:
- Understand the scope of the Enterprise Cybersecurity Program
- Identify the key components of the architecture
- Recognize the frameworks used
- Set expectations for the learning journey

### Key Concepts

**What is a Cybersecurity Program?**
A cybersecurity program is a comprehensive set of policies, procedures, controls, and technologies designed to protect an organization's information assets and ensure business continuity.

**Why This Matters:**
- $4.45M average breach cost (IBM 2023)
- 60%+ of breaches involve third parties

**Instructions:** Create a decision tree for classifying data.

```
Is the data publicly available?
  ├── YES → Level 1 (Public)
  └── NO → Does it contain personal information?
      ├── YES → Does it contain PII/PHI?
      │   ├── YES → Level 4 (Highly Confidential)
      │   └── NO → Level 3 (Confidential)
      └── NO → Does it contain business-sensitive info?
          ├── YES → Does it contain IP/trade secrets?
          │   ├── YES → Level 4 (Highly Confidential)
          │   └── NO → Level 3 (Confidential)
          └── NO → Level 2 (Internal)
```
