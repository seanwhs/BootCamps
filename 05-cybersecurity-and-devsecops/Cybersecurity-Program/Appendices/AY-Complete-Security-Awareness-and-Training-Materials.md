# Phishing Simulation Program

## 1. Overview

### 1.1 Program Purpose
To educate users on phishing threats and reduce click rates.

### 1.2 Program Objectives
1. Reduce phishing click rate to <5%
2. Increase phishing report rate to >10%
3. Build user awareness
4. Identify vulnerable users
5. Continuous improvement

## 3. Simulation Templates

### 3.1 Standard Template

```yaml
# Standard Phishing Template
phishing_template:
  subject: "Important Security Update"
  from: "security@company.com"
  body: |
    Dear [User],
    
    We have detected unusual activity on your account. Please verify your credentials immediately to prevent account suspension.
    
    [Link to verify]
    
    Thank you,
    Security Team
  
  indicators:
    - "Urgent language"
    - "Request for credentials"
    - "Generic greeting"
    - "Suspicious link"
```

### 3.2 Advanced Template

