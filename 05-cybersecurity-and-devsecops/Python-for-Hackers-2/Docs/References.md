## SCAPY CHEAT SHEET

### Building Packets

```python
# Basic packets
Ether(dst="ff:ff:ff:ff:ff:ff") / ARP(pdst="192.168.1.1")
IP(dst="8.8.8.8") / TCP(dport=80, flags="S")
IP(dst="8.8.8.8") / ICMP(type=8, code=0)

# Advanced packets
IP(dst="192.168.1.1", ttl=64, tos=0) / TCP(sport=12345, dport=80, flags="SA")
Ether(src="00:11:22:33:44:55", dst="ff:ff:ff:ff:ff:ff") / IP(dst="192.168.1.1")

# With payload
IP(dst="8.8.8.8") / TCP(dport=80, flags="PA") / Raw(load=b"GET / HTTP/1.1\r\n\r\n")
```

### Common Functions

| Function | Description | Example |
|----------|-------------|---------|
| `send(packet)` | Send at Layer 3 | `send(IP(dst="1.1.1.1")/ICMP())` |
| `sendp(packet)` | Send at Layer 2 | `sendp(Ether()/IP(dst="1.1.1.1"))` |
| `sr1(packet)` | Send and receive 1 response | `sr1(IP(dst="1.1.1.1")/ICMP())` |
| `sr(packet)` | Send and receive responses | `sr(IP(dst="1.1.1.1")/ICMP())` |
| `sniff()` | Capture packets | `sniff(filter="tcp", count=10)` |
| `rdpcap(file)` | Read PCAP | `rdpcap("capture.pcap")` |
| `wrpcap(file, packets)` | Write PCAP | `wrpcap("out.pcap", packets)` |
| `fuzz(packet)` | Fuzz a packet | `fuzz(IP()/TCP())` |
| `fragment(packet)` | Fragment a packet | `fragment(IP()/TCP())` |

### BPF Filter Examples

```python
# Protocol filters
"tcp" "udp" "icmp" "arp" "ip" "ip6"

# Port filters
"tcp port 80" "udp port 53" "tcp portrange 1-1024"

# Host filters
"host 192.168.1.1" "src 192.168.1.100" "dst 8.8.8.8"

# Network filters
"net 192.168.0.0/16" "src net 10.0.0.0/8"

# Combined filters
"tcp port 80 and host 192.168.1.1"
"(tcp port 80 or tcp port 443) and host 192.168.1.1"

# Negative filters
"not arp and not icmp" "not host 192.168.1.1"

# TCP flags
"tcp[13] & 0x02 != 0"  # SYN
"tcp[13] & 0x10 != 0"  # ACK
"tcp[13] == 0x12"      # SYN-ACK
```

### Field Access

```python
# IP Layer
packet[IP].src   # Source IP
packet[IP].dst   # Destination IP
packet[IP].ttl   # Time To Live
packet[IP].proto # Protocol number

# TCP Layer
packet[TCP].sport   # Source port
packet[TCP].dport   # Destination port
packet[TCP].seq     # Sequence number
packet[TCP].ack     # Acknowledgment number
packet[TCP].flags   # TCP flags (S, A, F, R, P, U)

# UDP Layer
packet[UDP].sport   # Source port
packet[UDP].dport   # Destination port

# ICMP Layer
packet[ICMP].type   # ICMP type
packet[ICMP].code   # ICMP code

# Ethernet Layer

packet[Ether].dst   # Destination MAC

# ARP Layer

packet[ARP].psrc    # Source IP
```

## ASYNCIO CHEAT SHEET

### Core Functions

| Function | Description |
|----------|-------------|
| `asyncio.run(coro())` | Run coroutine until complete |
| `asyncio.create_task(coro())` | Schedule task on event loop |
| `asyncio.gather(*coros)` | Run multiple coroutines concurrently |
| `asyncio.wait(tasks)` | Wait for tasks with conditions |
| `asyncio.wait_for(coro, timeout)` | Wait with timeout |
| `asyncio.sleep(seconds)` | Non-blocking sleep |
| `asyncio.shield(coro)` | Protect from cancellation |
| `asyncio.current_task()` | Get current task |
| `asyncio.all_tasks()` | Get all tasks |

### Common Patterns

```python
# Running multiple tasks
results = await asyncio.gather(
    task1(),
    task2(),
    task3()
)

# Timeout
try:
    result = await asyncio.wait_for(
        slow_operation(),
        timeout=5.0
    )
except asyncio.TimeoutError:
    result = None

# Queue
queue = asyncio.Queue()
await queue.put(item)
item = await queue.get()

# Lock
lock = asyncio.Lock()
async with lock:
    critical_section()

# Semaphore
semaphore = asyncio.Semaphore(10)
async with semaphore:
    await limited_operation()

# Event
event = asyncio.Event()
await event.wait()
event.set()
```

### Async Context Managers

```python
# Timeout context (Python 3.11+)
async with asyncio.timeout(5):
    await operation()

# Lock context
async with asyncio.Lock():
    # Critical section

# Semaphore context
async with asyncio.Semaphore(10):
    # Limited concurrency

# Custom context manager
async with MyAsyncContext() as ctx:
    await ctx.do_work()
```

### Thread Integration

```python
# Run blocking code in executor
loop = asyncio.get_event_loop()
result = await loop.run_in_executor(
    None,  # Default executor
    time.sleep,
    1
)

# With custom executor
executor = ThreadPoolExecutor(max_workers=5)
result = await loop.run_in_executor(
    executor,
    blocking_function,
    arg1, arg2
)
```

### Implementation Examples

```python
# Connect to single device
from netmiko import ConnectHandler

device = {
    'device_type': 'cisco_ios',
    'host': '192.168.1.1',
    'username': 'admin',
    'password': 'cisco123'
}

net_connect = ConnectHandler(**device)
output = net_connect.send_command('show ip int brief')
print(output)
net_connect.disconnect()

# Connect to multiple devices 
all_devices = [
    {'device_type': 'cisco_ios', 'host': '192.168.1.1', 'username': 'admin', 'password': 'cisco123'},
    {'device_type': 'cisco_asa', 'host': '192.168.1.2', 'username': 'admin', 'password': 'cisco123'},
]

for device in all_devices:
    net_connect = ConnectHandler(**device)
    output = net_connect.send_command('show version')
    print(f"\n--- {device['host']} ---")
    print(output)
    net_connect.disconnect()

# Send configuration commands 
commands = [
    'interface loopback 0',
    'ip address 1.1.1.1 255.255.255.255',
    'no shutdown'
]
output = net_connect.send_config_set(commands)
print(output)
```

## PARAMIKO CHEAT SHEET

### Authentication Methods

```python
import paramiko

# Password authentication
client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect(
    hostname='192.168.1.1',
    username='admin',
    password='password',
    port=22
)

# Private key authentication
key = paramiko.RSAKey.from_private_key_file('/path/to/id_rsa')
client.connect(
    hostname='192.168.1.1',
    username='admin',
    pkey=key
)

# SSH agent authentication
from paramiko.agent import Agent
agent = Agent()
for key in agent.get_keys():
    try:
        client.connect(hostname='192.168.1.1', username='admin', pkey=key)
        break
    except:
        continue
```

### Common Operations

```python
# Execute command
stdin, stdout, stderr = client.exec_command('ls -la')
output = stdout.read().decode()
error = stderr.read().decode()

# Execute with sudo
command = f"echo '{password}' | sudo -S {command} 2>&1"
stdin, stdout, stderr = client.exec_command(command)

# File upload
sftp = client.open_sftp()
sftp.put(local_path, remote_path)
sftp.close()

# File download
sftp = client.open_sftp()
sftp.get(remote_path, local_path)
sftp.close()

# Interactive shell
channel = client.invoke_shell()
channel.send('enable\n')
channel.send('conf t\n')
channel.send('interface Gi0/1\n')
channel.close()
```

### Best Practices

```python
# Use context manager
with paramiko.SSHClient() as client:
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    client.connect(hostname='192.168.1.1', username='admin')
    # Operations here

# With retries
def connect_with_retry(hostname, username, password, retries=3):
    for attempt in range(retries):
        try:
            client = paramiko.SSHClient()
            client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
            client.connect(hostname, username=username, password=password)
            return client
        except paramiko.AuthenticationException:
            if attempt == retries - 1:
                raise
            time.sleep(2 ** attempt)
```

## SECURITY CHECKLIST

### Input Validation

- [ ] **Path traversal prevention**: Validate and normalize file paths
- [ ] **Command injection prevention**: Use subprocess with lists, sanitize input
- [ ] **SQL injection prevention**: Use parameterized queries
- [ ] **XSS prevention**: Escape HTML output, use Content Security Policy
- [ ] **Deserialization safety**: Use JSON, restrict pickle

### Authentication

- [ ] **Password hashing**: Use bcrypt or Argon2 (never MD5 or SHA1)
- [ ] **Rate limiting**: Implement on login attempts
- [ ] **Session management**: Use timeouts and secure session IDs
- [ ] **MFA**: Implement multi-factor authentication
- [ ] **Password policies**: Enforce strong passwords

### Data Protection

- [ ] **Encryption at rest**: Use AES-256 for stored data
- [ ] **Encryption in transit**: Use TLS/SSL with certificate validation
- [ ] **Log redaction**: Remove sensitive data from logs
- [ ] **Secret management**: Use environment variables or vault
- [ ] **Data retention**: Implement proper data lifecycle

### Network Security

- [ ] **SSL/TLS**: Use strong protocols, disable SSLv2/SSLv3/TLSv1.0
- [ ] **Certificate validation**: Always verify certificates
- [ ] **SSH security**: Use key authentication, disable password if possible
- [ ] **Firewall**: Restrict exposed ports
- [ ] **Network segmentation**: Isolate sensitive systems

### Code Security

- [ ] **Dependency scanning**: Use pip-audit, safety
- [ ] **Regular updates**: Keep dependencies current
- [ ] **Static analysis**: Use bandit, pylint
- [ ] **Secrets in code**: Never commit secrets
- [ ] **Secure defaults**: Use safe configurations

### Monitoring

- [ ] **Audit logging**: Log security events
- [ ] **Alerting**: Set up alerts for suspicious activity
- [ ] **Intrusion detection**: Monitor for attacks
- [ ] **Regular audits**: Conduct security assessments
- [ ] **Incident response**: Have a plan for breaches

### Development Process

- [ ] **Threat modeling**: Identify potential threats
- [ ] **Security training**: Keep team informed
- [ ] **Code review**: Include security review
- [ ] **Testing**: Include security tests
- [ ] **Documentation**: Document security measures
