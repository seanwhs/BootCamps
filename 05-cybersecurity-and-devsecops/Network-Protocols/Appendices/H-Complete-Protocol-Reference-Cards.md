## 2. Data Link Layer Reference Cards

### Ethernet II Frame

```
┌─────────────────────────────────────────────────────────────┐
│                   ETHERNET II FRAME                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Preamble (7 bytes)                               │    │
│  │  - 10101010 repeated 7 times                     │    │
│  │  - Synchronizes receiver clock                   │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  SFD (1 byte)                                    │    │
│  │  - Start Frame Delimiter: 10101011               │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Destination MAC (6 bytes)                        │    │
│  │  - Recipient's MAC address                       │    │
│  │  - FF:FF:FF:FF:FF:FF = Broadcast                 │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Source MAC (6 bytes)                             │    │
│  │  - Sender's MAC address                          │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  EtherType/Length (2 bytes)                       │    │
│  │  - >= 0x0600: EtherType                          │    │
│  │  - < 0x0600: Frame Length                        │    │
│  │  - 0x0800 = IPv4                                 │    │
│  │  - 0x0806 = ARP                                  │    │
│  │  - 0x86DD = IPv6                                 │    │
│  │  - 0x8100 = VLAN                                 │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Payload (46-1500 bytes)                          │    │
│  │  - Encapsulated data                             │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  FCS (4 bytes)                                    │    │
│  │  - CRC-32 checksum                               │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  Total: 64-1518 bytes (excluding preamble)                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
```

```
│  │  - 20-60 bytes                                    │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  DSCP (6 bits)                                    │    │

│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │

│  ┌────────────────────────────────────────────────────┐    │

│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Flags (3 bits)                                   │    │

│  ┌────────────────────────────────────────────────────┐    │

│  ┌────────────────────────────────────────────────────┐    │

│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Header Checksum (16 bits)                        │    │

│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Source IP (32 bits)                              │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Destination IP (32 bits)                         │    │
│  └────────────────────────────────────────────────────┘    │
│  ┌────────────────────────────────────────────────────┐    │
```

### QUIC vs TCP Comparison

```
┌─────────────────────────────────────────────────────────────┐
│              QUIC vs TCP COMPARISON                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Connection Establishment:                        │    │
│  │  ├─ TCP: 2-3 RTT (with TLS)                       │    │
│  │  └─ QUIC: 1 RTT (0-RTT with resumption)          │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Multiplexing:                                    │    │
│  │  ├─ TCP: One stream per connection               │    │
│  │  └─ QUIC: Multiple independent streams            │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Head-of-Line Blocking:                           │    │
│  │  ├─ TCP: Present (one stream blocks all)         │    │
│  │  └─ QUIC: Eliminated (streams are independent)   │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Connection Migration:                            │    │
│  │  ├─ TCP: Breaks on IP change                     │    │
│  │  └─ QUIC: Connection ID persists                   │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Security:                                        │    │
│  │  ├─ TCP: Optional (TLS)                           │    │
│  │  └─ QUIC: Mandatory (TLS 1.3 built-in)           │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Congestion Control:                              │    │
│  │  ├─ TCP: Fixed algorithms                         │    │
│  │  └─ QUIC: Pluggable, per-stream                  │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌────────────────────────────────────────────────────┐    │
│  │  Transport Layer:                                 │    │
│  │  ├─ TCP: TCP (reliable, ordered)                 │    │
│  │  └─ QUIC: UDP (reliable, unordered)              │    │
│  └────────────────────────────────────────────────────┘    │
```
