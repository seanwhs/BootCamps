# Primer 8: The Career Primer - Land Your First PM Role

## Overview

This primer is designed for readers who want to transition into product management. It covers the entire journey—from building your skills and portfolio to applying for roles and acing interviews.

**Purpose:** To give you a complete, actionable roadmap for landing your first product management role, in 15 minutes.

---

## What This Primer Covers

1. **The PM Career Landscape** (What Roles Exist and How to Get In)
2. **The Skills You Need** (And How to Build Them)
3. **The Portfolio** (Your Proof of Ability)
4. **The Job Search** (Where and How to Apply)
5. **The Resume** (How to Position Yourself)
6. **The Interview** (What to Expect and How to Prepare)
7. **Your Career Mantra** (The One Mindset That Will Carry You Through)

### How to Build Skills Without a PM Job

| Skill | How to Build It |
|-------|-----------------|
| **User Research** | Interview friends about products they use; read about research methods |
| **Product Strategy** | Analyze a product you love; write a strategy for it |
| **Prioritization** | Apply RICE to features in a product you use |
| **Requirement Writing** | Write a PRD for a feature you'd want (like Ledgerly) |
| **Metrics** | Define metrics for a product you use |
| **Technical** | Take an introductory coding course (CS50) |
| **Business** | Read business books; understand P&L |
| **Communication** | Write about products; blog; practice explaining concepts |

### How to Present Your Portfolio

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     PORTFOLIO PRESENTATION FRAMEWORK                    │
│                                                                         │
│  1. INTRODUCTION (2-3 min)                                              │
│     ───────────────────                                                │
│     • Introduce yourself and the product                               │
│     • Set the context                                                 │
│                                                                         │
│  2. THE PROBLEM (2-3 min)                                              │
│     ──────────────────                                                │
│     • What was the problem?                                           │
│     • Why did it matter?                                              │
│     • What were the key insights?                                     │
│                                                                         │
│  3. THE SOLUTION (3-5 min)                                            │
│     ──────────────────                                                │
│     • What did you build?                                             │
│     • What was the strategy?                                          │
│     • How did you prioritize?                                         │
│                                                                         │
│  4. THE EXECUTION (3-5 min)                                           │
│     ──────────────────                                                │
│     • How did you work with engineering?                              │
│     • How did you manage scope?                                      │
│     • What did you ship?                                             │
│                                                                         │
│  5. THE RESULTS (2-3 min)                                             │
│     ─────────────────                                                 │
│     • What were the results?                                          │
│     • What metrics improved?                                          │
│     • What did you learn?                                            │
│                                                                         │
│  6. THE ITERATION (2-3 min)                                           │
│     ──────────────────                                                │
│     • How did you iterate?                                           │
│     • What's next?                                                    │
│     • What would you do differently?                                 │
│                                                                         │
│  7. QUESTIONS (remaining time)                                        │
│     ───────────────────                                               │
│     • Be prepared for deep dives                                     │
│     • Be ready to defend trade-offs                                  │
└─────────────────────────────────────────────────────────────────────────┘
```
