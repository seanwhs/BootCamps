# References & Resources Guide: The Zero-to-One Product Manager

## Your Complete Bibliography and Learning Resource Directory

---

## How to Use This Guide

This guide provides a comprehensive collection of references, resources, and further reading materials to support your product management journey. It is organized into:

1. **Recommended Books** - Essential PM reading, categorized by topic
2. **Online Courses** - Structured learning opportunities
3. **Podcasts** - Audio learning for commuters and multi-taskers
4. **Blogs & Newsletters** - Ongoing PM insights and community
5. **Tools & Templates** - Practical resources for PM work
6. **Frameworks Reference** - Deep dives into key frameworks
7. **Academic References** - Research underpinning PM practice
8. **Community & Events** - Professional networking opportunities

---

### Quick Reference: RICE Framework

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     RICE FRAMEWORK REFERENCE                            │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  RICE = (Reach × Impact × Confidence) ÷ Effort                  │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  COMPONENTS:                                                           │
│  ────────────                                                         │
│  • Reach: Number of users affected                                    │
│  • Impact: 3=Massive, 2=High, 1=Medium, 0.5=Low, 0.25=Minimal      │
│  • Confidence: 100%=High, 80%=Medium, 50%=Low                       │
│  • Effort: Person-months or story points                             │
│                                                                         │
│  WHEN TO USE:                                                          │
│  ────────────                                                         │
│  • Prioritizing features                                             │
│  • Making trade-off decisions                                       │
│  • Defending prioritization to stakeholders                         │
│                                                                         │
│  ALTERNATIVES:                                                         │
│  ─────────────                                                       │
│  • WSJF (Weighted Shortest Job First)                               │
│  • Opportunity Scoring                                               │
│  • Impact/Effort Matrix                                             │
│                                                                         │
│  FURTHER READING:                                                     │
│  ────────────────                                                     │
│  • Intercom's "How to Prioritize Features"                          │
│  • ProductPlan's "RICE Scoring Guide"                               │
└─────────────────────────────────────────────────────────────────────────┘
```

### Quick Reference: Kano Model

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     KANO MODEL REFERENCE                                │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  THE 4 CATEGORIES                                                │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  • Basic Features (Table Stakes): Absence causes dissatisfaction      │
│    Examples: Account aggregation, secure login, data privacy         │
│                                                                         │
│  • Performance Features (More is Better): Linear satisfaction         │
│    Examples: Budgeting, goal setting, reporting                      │

│  • Excitement Features (Delighters): Unexpected value                │
│    Examples: Actionable insights, gamification, weekly summaries     │

│  • Indifferent Features: No significant impact on satisfaction       │
│    Examples: Niche features, "nice to have" capabilities            │
│                                                                         │
│  WHEN TO USE:                                                          │
│  ────────────                                                         │
│  • Understanding feature priorities                                  │
│  • Identifying differentiators                                      │
│  • Managing stakeholder expectations                                │
│                                                                         │
│  FURTHER READING:                                                     │
│  ────────────────                                                     │
│  • "Kano Model: A Comprehensive Guide" by ProductPlan               │
```

## Part 10: Quick Reference Card

### Key Frameworks Summary

| Framework | Formula/Mnemonic | When to Use |
|-----------|------------------|-------------|
| **RICE** | Reach × Impact × Confidence ÷ Effort | Prioritization |
| **Kano** | Basic, Performance, Excitement | Feature categorization |
| **JTBD** | "What job is the user hiring?" | Understanding users |
| **AARRR** | Acquisition, Activation, Retention, Referral, Revenue | User lifecycle |
| **Growth Pyramid** | Retention → Activation → Acquisition → Revenue | Growth strategy |
| **STAR** | Situation, Task, Action, Result | Behavioral answers |
| **SWOT** | Strengths, Weaknesses, Opportunities, Threats | Competitive analysis |

### Key Metrics Summary

| Metric | Definition | Formula |
|--------|------------|---------|
| **NPS** | Net Promoter Score | Promoters% - Detractors% |
| **Retention** | % active after X days | Active / Total |
| **Churn** | % who stop using | Users lost / Total |
| **ARPU** | Average Revenue Per User | Revenue / Users |
| **LTV** | Lifetime Value | ARPU × Lifetime |
| **CAC** | Customer Acquisition Cost | Marketing / New Users |
| **DAU/MAU** | Engagement | Daily / Monthly |

### Key PM Mantras

| Context | Mantra |
|---------|--------|
| **Mindset** | "What problem are we solving, and how will we know if we solved it?" |
| **Strategy** | "We serve [who] with [what] so they can [outcome], and we're willing to give up [what] to do it." |
| **Discovery** | "What is the user trying to accomplish, and what's preventing them from doing it?" |
| **Execution** | "Build the simplest thing that could possibly work, ship it, and learn from what happens next." |
| **Metrics** | "What metric would tell us we're succeeding, and what would we do if it moved?" |
| **Stakeholders** | "Communicate early, communicate often, and always tie decisions back to the user and the business." |
| **Career** | "The best way to become a product manager is to start doing product management. Right now. With what you have. Where you are." |
