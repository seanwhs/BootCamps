# Primer 3: The Product Strategy Primer - Think Like a PM Leader

## Overview

This primer is designed for readers who want to understand the **strategic side** of product management. While most beginners focus on execution (writing PRDs, working with engineering), the real differentiator is strategic thinking—the ability to see the big picture, make tough trade-offs, and align product decisions with business goals.

**Purpose:** To give you the strategic mindset and frameworks you need to think like a senior PM, in 15 minutes.

## 1. What Product Strategy Actually Is

### The 30-Second Definition

> **Product Strategy is the set of choices you make about where to play and how to win, given your constraints and opportunities.**

### What Strategy IS vs. What Strategy ISN'T

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     STRATEGY: WHAT IT IS VS. WHAT IT ISN'T              │
│                                                                         │
│  ✅ STRATEGY IS:                                                        │
│  ────────────────────                                                  │
│  • A set of choices                                                   │
│  • A plan to win                                                      │
│  • A clear "where to play" and "how to win"                          │
│  • A guide for decision-making                                       │
│  • A statement of trade-offs                                         │
│  • Something that aligns the team                                    │
│                                                                         │
│  ❌ STRATEGY IS NOT:                                                   │
│  ──────────────────────                                               │
│  • A list of features                                                │
│  • A product roadmap                                                 │
│  • A wish list                                                       │
│  • Something that never changes                                      │
│  • A PowerPoint deck                                                 │
│  • A buzzword-filled document                                        │
└─────────────────────────────────────────────────────────────────────────┘
```

### The Strategy Test

Here's a simple test to see if you have a strategy:

> *"If your team disagrees about what to build next, does your strategy help you decide?"*

If yes → You have a strategy.
If no → You don't have a strategy (you just have a list of things you want to build).

## 2. The 5 Strategic Questions Every PM Must Answer

Great product strategy answers five fundamental questions:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     5 STRATEGIC QUESTIONS                               │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  QUESTION 1: WHO ARE WE SERVING?                                │   │
│  │  ───────────────────────────────────────────────────────────── │   │
│  │  • Who is our target audience?                                 │   │
│  │  • What are their characteristics?                             │   │
│  │  • What segment(s) are we focusing on?                        │   │
│  │                                                                 │   │
│  │  Example: "Young professionals (25-40) who want financial      │   │
│  │  confidence but don't know where to start."                    │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  QUESTION 2: WHAT NEED ARE WE MEETING?                         │   │
│  │  ───────────────────────────────────────────────────────────── │   │
│  │  • What is the job the user is hiring us to do?               │   │
│  │  • What's the core value we provide?                           │   │
│  │  • What's the "why" behind our product?                       │   │
│  │                                                                 │   │
│  │  Example: "We help users feel in control of their finances     │   │
│  │  through simplicity, guidance, and progress tracking."        │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  QUESTION 3: WHY ARE WE DIFFERENT?                             │   │
│  │  ───────────────────────────────────────────────────────────── │   │
│  │  • What makes us unique?                                       │   │
│  │  • Why choose us over competitors?                            │   │
│  │  • What's our competitive advantage?                           │   │
│  │                                                                 │   │
│  │  Example: "We are simpler than YNAB, more guiding than Mint,  │   │
│  │  and privacy-first compared to competitors."                   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  QUESTION 4: HOW WILL WE WIN?                                  │   │
│  │  ───────────────────────────────────────────────────────────── │   │
│  │  • What is our path to success?                                │   │
│  │  • What's our growth strategy?                                 │   │
│  │  • How do we acquire, retain, and monetize users?            │   │
│  │                                                                 │   │
│  │  Example: "We'll activate users through simplified onboarding, │   │
│  │  retain through goal-setting, and scale through referrals."   │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                                                         │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │  QUESTION 5: WHAT ARE WE WILLING TO GIVE UP?                  │   │
│  │  ───────────────────────────────────────────────────────────── │   │
│  │  • What are we NOT doing?                                     │   │
│  │  • What markets are we NOT serving?                           │   │
│  │  • What features are we NOT building?                         │   │
│  │                                                                 │   │
│  │  Example: "We are NOT building investment tracking. We are NOT│   │
│  │  serving high-net-worth individuals. We are NOT building a    │   │
│  │  full-featured budgeting platform (yet)."                     │   │
│  └─────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
```

### The Strategy Answer Template

> "We serve **[target audience]** who need **[core need]** . We differentiate by **[unique advantage]** . We will win by **[growth strategy]** , and we are willing to give up **[what we're NOT doing]** ."

Strategy isn't one thing—it's a hierarchy. Think of it as a stack:

┌─────────────────────────────────────────────────────────────────────────┐
│                     THE STRATEGY STACK                                  │
│                                                                         │
│                    ┌─────────────────────────────────────┐             │
│                    │          PRODUCT VISION             │             │
│                    │   "Make financial confidence        │             │
│                    │    accessible to everyone."         │             │
│                    └──────────────┬──────────────────────┘             │
│                                   │                                     │
│                    ┌──────────────▼──────────────────────┐             │
│                    │        PRODUCT STRATEGY             │             │
│                    │   "Serve young professionals with   │             │
│                    │    simplicity, guidance, and        │             │
│                    │    progress tracking."              │             │
│                    └──────────────┬──────────────────────┘             │
│                                   │                                     │
│                    ┌──────────────▼──────────────────────┐             │
│                    │        PRODUCT ROADMAP              │             │
│                    │   "Q1: Goal Setting                │             │
│                    │    Q2: Budgeting                   │             │
│                    │    Q3: Insights"                    │             │
│                    └──────────────┬──────────────────────┘             │
│                                   │                                     │
│                    ┌──────────────▼──────────────────────┐             │
│                    │        PRODUCT BACKLOG              │             │

## 4. The 4 Types of Product Strategy

### Which One Are You Using?

| Strategy Type | Description | Example | When to Use |
|---------------|-------------|---------|-------------|
| **Disruption** | Challenge incumbents with a lower-cost or simpler solution | Spotify (vs. record labels), Airbnb (vs. hotels) | When incumbents are expensive or complex |
| **Differentiation** | Offer superior features, quality, or experience | Apple, Tesla | When users value quality over price |
| **Cost Leadership** | Be the lowest-cost provider | Walmart, Southwest Airlines | When users are price-sensitive |
| **Niche Focus** | Serve a specific segment better than anyone else | Ledgerly (young professionals), Shopify (small businesses) | When a segment is underserved |

### The Strategy Spectrum

```
                  COST                      QUALITY
                  ▲                           ▲
                  │                           │
                  │    COST                   │    DIFFERENTIATION
                  │    LEADERSHIP             │
                  │    (Low price,            │    (Superior product,
                  │     mass market)          │     premium experience)
                  │                           │
                  │    ────────────────────────┼────────────────────────
                  │                           │
                  │    NICHE FOCUS            │    DISRUPTION
                  │    (Serve one segment     │    (Challenge incumbents
                  │     well)                 │     with simpler solution)
                  │                           │
                  ▼                           ▼
                NARROW                     BROAD
                (Serves specific           (Serves mass
                 segment)                  market)
```

## 5. The Strategy Diagnostic

### Is Your Strategy Working?

Answer these questions to diagnose your strategy:

**1. Clarity:**
- [ ] Can every team member articulate the strategy in 2 minutes?
- [ ] Does the strategy guide day-to-day decisions?
- [ ] Does the strategy answer "who, what, why, how, and what we give up"?

**2. Alignment:**
- [ ] Do your roadmap, backlog, and strategy all align?
- [ ] Do your metrics reflect your strategy?
- [ ] Are stakeholders bought into the strategy?

**3. Trade-offs:**
- [ ] Have you made explicit trade-offs?
- [ ] Is it clear what you're NOT doing?
- [ ] Can you say "no" to features that don't fit the strategy?

**4. Execution:**
- [ ] Are you actually following the strategy?
- [ ] Are you measuring progress against the strategy?
- [ ] Are you iterating based on feedback and data?

### The Strategy Scorecard

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     STRATEGY SCORECARD                                  │
│                                                                         │
│  Score each question 1-5 (1 = Poor, 5 = Excellent):                   │
│                                                                         │
│  1. Everyone can articulate the strategy         [__]                  │
│  2. Strategy guides day-to-day decisions         [__]                  │
│  3. Trade-offs are clear                          [__]                  │
│  4. Roadmap and backlog align with strategy      [__]                  │
│  5. Metrics reflect strategy                      [__]                  │
│  6. Stakeholders are aligned                      [__]                  │
│  7. We're actually following the strategy        [__]                  │
│  8. We're measuring progress                      [__]                  │
│  9. We're iterating based on feedback            [__]                  │
│  10. The strategy is clear to everyone           [__]                  │
│                                                                         │
│  TOTAL: ___ / 50                                                       │
│                                                                         │
│  40-50: Strong strategy                                              │

│  10-19: No strategy, start from scratch                               │
│  0-9:   Strategy crisis, rebuild immediately                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 6. The 5 Strategic Trade-offs

Great strategy is defined by what you **give up** as much as what you pursue.

### Trade-off 1: Breadth vs. Depth

**Decision:** Serve many segments shallowly OR serve one segment deeply.

**Ledgerly's Choice:** Depth over breadth. We serve young professionals deeply rather than everyone shallowly.

### Trade-off 2: Speed vs. Quality

**Decision:** Ship fast and iterate OR ship perfect and polish.

**Ledgerly's Choice:** Speed over perfection. We ship MVPs and iterate based on feedback.

### Trade-off 3: New Features vs. Maintenance

**Decision:** Build new things OR maintain existing ones.

**Ledgerly's Choice:** 80% new features, 20% maintenance. We invest in growth but don't neglect technical debt.

### Trade-off 4: User Growth vs. Revenue

**Decision:** Grow user base OR maximize revenue per user.

**Ledgerly's Choice:** Growth over revenue (initially). We're building scale before monetizing.

### Trade-off 5: Simplicity vs. Feature Richness

**Decision:** Keep it simple OR add more features.

**Ledgerly's Choice:** Simplicity over features. We'd rather be loved by few than tolerated by many.

## 8. Strategic Pitfalls to Avoid

### 5 Mistakes New PMs Make

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     5 STRATEGIC PITFALLS                                │
│                                                                         │
│  PITFALL 1: CONFUSING STRATEGY WITH A ROADMAP                         │
│  ─────────────────────────────────────────────────────────────────    │
│  ❌ Mistake: "Our strategy is to build features X, Y, and Z."       │
│  ✅ Fix: A roadmap is *what* you'll build; strategy is *why* and    │
│  *how* you'll win.                                                   │
│                                                                         │
│  PITFALL 2: TRYING TO BE EVERYTHING TO EVERYONE                       │
│  ─────────────────────────────────────────────────────────────────    │
│  ❌ Mistake: "We'll serve everyone who wants personal finance."     │
│  ✅ Fix: "We'll serve young professionals who are new to budgeting." │
│  Strategy requires focus and trade-offs.                              │
│                                                                         │
│  PITFALL 3: NOT HAVING A CLEAR "NO"                                  │
│  ─────────────────────────────────────────────────────────────────    │
│  ❌ Mistake: "We can't say no to any feature request."              │
│  ✅ Fix: "We're not building investment tracking because it doesn't │
│  serve our core audience."                                           │
│                                                                         │
│  PITFALL 4: STRATEGY THAT DOESN'T ALIGN WITH METRICS                 │
│  ─────────────────────────────────────────────────────────────────    │
│  ❌ Mistake: "Our strategy is retention, but our metrics are about │
│  acquisition."                                                       │
│  ✅ Fix: "Our North Star metric is weekly active users with a goal." │
│  Metrics must reflect the strategy.                                  │
│                                                                         │
│  PITFALL 5: STRATEGY THAT NEVER CHANGES                              │
│  ─────────────────────────────────────────────────────────────────    │
│  ❌ Mistake: "We set our strategy 2 years ago and haven't changed    │
│  it."                                                                │
│  ✅ Fix: "We review our strategy quarterly and adjust based on data │
│  and learning."                                                      │
│  Strategy evolves as you learn.                                      │
└─────────────────────────────────────────────────────────────────────────┘
```

## 9. Your Strategic Mantra

### The One Sentence That Will Guide You

When you're confused about strategy, when stakeholders are pulling you in different directions, when you don't know what to prioritize—come back to this:

> *"We serve [who] with [what] so they can [outcome], and we're willing to give up [what] to do it."*

### Fill in the Blanks for Ledgerly

> "We serve **young professionals** who want **financial confidence** so they can **feel in control of their money**, and we're willing to give up **building for everyone, complex features, and chasing every opportunity** to do it."

### Why This Works

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     THE STRATEGIC MANTRA                                │
│                                                                         │
│  "WE SERVE [WHO]..."                                                  │
│  ───────────────────────────────────────────────────────────────       │
│  • Defines your target audience                                      │
│  • Forces focus                                                       │
│  • Prevents "everyone" thinking                                       │
│                                                                         │
│  "...WITH [WHAT]..."                                                  │
│  ───────────────────────────────────────────────────────────────       │
│  • Defines your value proposition                                    │
│  • Clarifies what you deliver                                         │
│  • Sets expectations for your product                                │
│                                                                         │
│  "...SO THEY CAN [OUTCOME]..."                                       │
│  ───────────────────────────────────────────────────────────────       │
│  • Defines the user outcome                                           │
│  • Clarifies why your product matters                                 │
│  • Motivates your team                                                │
│                                                                         │
│  "...AND WE'RE WILLING TO GIVE UP [WHAT]..."                        │
│  ───────────────────────────────────────────────────────────────       │
│  • Defines your trade-offs                                            │
│  • Prevents scope creep                                               │
│  • Makes hard decisions easier                                        │
└─────────────────────────────────────────────────────────────────────────┘
```

### Use Your Mantra to Make Decisions

| Decision | Ask Your Mantra | Answer |
|----------|-----------------|--------|
| "Should we build investment tracking?" | Does it serve young professionals? | No, it serves advanced users |
| "Should we add a referral program?" | Does it help them feel in control? | It helps them, but indirectly—maybe later |
| "Should we reduce onboarding friction?" | Does it help them get financial confidence? | Yes, it removes barriers |
