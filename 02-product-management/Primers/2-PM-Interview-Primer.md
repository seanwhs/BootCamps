## 2. The 5 Types of PM Interview Questions

### Type 1: Behavioral Questions (STAR Format)

**The Framework: STAR**

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     STAR FRAMEWORK                                      │
│                                                                         │
│  S = SITUATION                                                         │
│  ─────────────                                                         │
│  Set the context. What was happening? Who was involved?                │
│                                                                         │
│  T = TASK                                                              │
│  ────────                                                             │
│  What were you trying to achieve? What was your responsibility?       │
│                                                                         │
│  A = ACTION                                                            │
│  ──────────                                                           │
│  What did you actually do? What steps did you take?                   │
│                                                                         │
│  R = RESULT                                                            │
│  ──────────                                                           │
│  What was the outcome? What did you learn? What metrics improved?     │
└─────────────────────────────────────────────────────────────────────────┘
```

**Sample Behavioral Questions:**
1. "Tell me about a time you made a difficult product decision."
2. "Tell me about a time you worked with a difficult stakeholder."
3. "Tell me about a time you failed and what you learned."
4. "Tell me about a time you had to prioritize between competing features."
5. "Tell me about a time you had to say 'no' to a stakeholder."

### Type 2: Product Sense Questions (Design Exercise)

**The Framework: Product Design**

```
┌─────────────────────────────────────────────────────────────────────────┐
│                     PRODUCT DESIGN FRAMEWORK                            │
│                                                                         │
│  1. CLARIFY THE PROBLEM                                                │
│     ──────────────────                                                │
│     • Ask clarifying questions                                        │
│     • Understand the user and their context                           │
│     • Define what success looks like                                  │
│                                                                         │
│  2. UNDERSTAND THE USER                                                │
│     ──────────────────                                                │
│     • Who is the user?                                                │
│     • What are their goals and pains?                                 │
│     • What's the "job to be done"?                                    │
│                                                                         │
│  3. BRAINSTORM SOLUTIONS                                               │
│     ─────────────────────                                             │
│     • Generate multiple ideas                                         │
│     • Don't settle on the first one                                   │
│     • Consider trade-offs                                             │
│                                                                         │
│  4. PRIORITIZE FEATURES                                                │
│     ────────────────────                                              │
│     • What's the MVP?                                                │
│     • What can be deferred?                                          │
│     • What's the user journey?                                       │
│                                                                         │
│  5. STRUCTURE THE EXPERIENCE                                           │
│     ─────────────────────────                                         │
│     • Walk through the user flow                                      │
│     • Describe key screens                                            │
│     • Consider edge cases and errors                                 │
│                                                                         │
│  6. MEASURE SUCCESS                                                    │
│     ────────────────────                                              │
│     • How will you know if it worked?                                │
│     • What metrics will you track?                                    │
│     • How will you iterate?                                           │
└─────────────────────────────────────────────────────────────────────────┘
```

**Sample Product Sense Questions:**
1. "Design a goal-setting feature for Ledgerly."
2. "Design a checkout experience for an e-commerce app."
3. "Design a notification system for a messaging app."

## 3. The PM Interview Cheat Sheet

### Key Frameworks at a Glance

| Framework | When to Use | How to Remember |
|-----------|-------------|-----------------|
| **RICE** | Prioritization | Reach × Impact × Confidence ÷ Effort |
| **Kano** | Feature categorization | Basic, Performance, Excitement |
| **JTBD** | Understanding users | "What job is the user hiring?" |
| **STAR** | Behavioral answers | Situation, Task, Action, Result |
| **AARRR** | User lifecycle | Acquisition, Activation, Retention, Referral, Revenue |
| **Growth Pyramid** | Growth strategy | Retention → Activation → Acquisition → Revenue |

### Key Metrics at a Glance

| Metric | What It Measures | Quick Formula |
|--------|------------------|---------------|
| **NPS** | Satisfaction | Promoters% - Detractors% |
| **Retention** | Loyalty | % of users active after X days |
| **Churn** | Loss | % of users who stop using product |
| **ARPU** | Revenue per user | Total revenue / Total users |
| **LTV** | Lifetime value | ARPU × Average customer lifetime |
| **CAC** | Acquisition cost | Marketing spend / New users |
| **DAU/MAU** | Engagement | Daily active / Monthly active |

## 5. The 10 Most Common PM Interview Questions (With Sample Answers)

### Question 1: "Tell me about yourself."

**Sample Answer:**
"I'm a product manager who's passionate about building products that help people feel in control of their finances. My background is in [marketing/engineering/design], and I've always been drawn to the intersection of user needs and business goals. I've developed a strong skill set in user research, prioritization, and working cross-functionally with engineering and design teams. I'm particularly excited about the opportunity to bring my experience to [Company Name]."

---

### Question 2: "Why do you want to be a PM?"

**Sample Answer:**
"I want to be a PM because I love solving problems that matter to people. I'm fascinated by how products can change behavior and improve lives. I also enjoy the challenge of balancing multiple perspectives—user needs, business goals, and technical constraints. I'm not satisfied with just building things; I want to build the right things."

---

### Question 3: "Tell me about a time you had to make a difficult product decision."

**STAR Answer:**
- **Situation:** "At Ledgerly, we had 10 features in the backlog and limited engineering capacity."
- **Task:** "I needed to prioritize the feature that would have the biggest impact on user retention."
- **Action:** "I used RICE scoring to evaluate each feature. Goal Setting had the highest score (Reach: 50,000, Impact: 3, Confidence: 85%, Effort: 2 → Score: 63,750). I presented my analysis to stakeholders and got buy-in."
- **Result:** "We shipped Goal Setting, achieving 32% goal adoption and increasing Day 30 retention from 20% to 40% for goal-setting users."

---

### Question 4: "Tell me about a time you had to work with a difficult stakeholder."

**STAR Answer:**
- **Situation:** "The Head of Marketing wanted to build a referral program immediately to drive growth."
- **Task:** "I needed to align our roadmap around retention (the real problem) while respecting Marketing's goals."
- **Action:** "I scheduled a meeting and walked her through our data: 80% churn within 30 days, goal-setting users retain at 3x. I proposed a compromise: fix retention first, then build the referral program."
- **Result:** "She agreed. We shipped Goal Setting, improved retention, and built the referral program the next quarter."

---

### Question 5: "Tell me about a time you failed and what you learned."

**STAR Answer:**
- **Situation:** "I assumed users would naturally engage with our redesigned dashboard without testing it first."
- **Task:** "Redesign the dashboard to improve engagement."
- **Action:** "I designed a dashboard I thought was intuitive. But after launch, users were confused and engagement didn't improve."
- **Result:** "I realized my mistake: I hadn't tested with users. I ran usability testing, got feedback, redesigned the dashboard with a clearer goal-setting prompt, and engagement improved by 30%. I learned: always test with users before launch."

---

### Question 6: "Design a feature for [product]."

**Sample Answer Outline:**
- **Clarify:** "Can I ask a few clarifying questions? Who is the user? What's the context?"
- **User:** "The user is Sarah, a 26-year-old Marketing Coordinator. She wants to save for a vacation but doesn't know how."
- **Problem:** "She needs a clear, achievable goal to work toward."
- **Solution:** "The MVP is a goal-setting feature where users can set a savings goal with a target amount and deadline."
- **Flow:** "User clicks 'Set a Goal' → Select goal type → Enter parameters → Confirm and save."
- **Metrics:** "Goal adoption (50%), retention (40%), NPS (4.5+)."

---

### Question 7: "How would you grow [product]?"

**Sample Answer Outline:**
- **Current State:** "The product has 50,000 users, 12,000 WAU, 20% Day 30 retention."
- **Opportunities:** "Onboarding friction (25% drop-off), low goal adoption (32%), no referral program."
- **Strategy:** "'Activate, Engage, and Scale.' We'll fix retention first."
- **Roadmap:** "Q1: Improve onboarding and goal adoption. Q2: Launch referral program and SEO. Q3: Expand features. Q4: Scale acquisition."
- **Metrics:** "WAU (target: 50,000), Retention (target: 40%), Goal adoption (target: 60%)."

---

### Question 8: "What metrics would you track for [feature]?"

**Sample Answer Outline:**
- **North Star:** "Weekly Active Users with a Goal."
- **Acquisition:** "Signups, goal page views, goal creation starts."
- **Activation:** "Goal adoption rate, goal completion rate."
- **Retention:** "Day 30 retention for goal-setters vs. non-goal-setters."
- **Revenue:** "Revenue from premium tier, referrals from goal-setters."
- **Health:** "NPS for goal-setters, goal abandonment rate."

---

### Question 9: "How do you prioritize features?"

**Sample Answer:**
"I use a combination of RICE scoring, Kano model, and outcome-based prioritization. I start by evaluating each feature on Reach, Impact, Confidence, and Effort. Then I categorize them using the Kano model (Basic, Performance, Excitement). Finally, I align them with business outcomes (retention, activation, revenue). This gives me a defensible, data-driven approach."

---

### Question 10: "What's your biggest weakness?"

**Sample Answer:**
"I tend to be a perfectionist, which can sometimes slow me down. I've learned to overcome this by focusing on the 'minimum viable product' and iterating based on feedback. I also set clear time-boxes for decision-making to avoid analysis paralysis."

## 8. Your Personal PM Interview Mantra

> *"What problem are we solving, and how will we know if we solved it?"*
