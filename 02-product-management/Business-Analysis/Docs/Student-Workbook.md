### About This Workbook

This workbook is designed to accompany the "Master Business Analysis: From Strategy to Execution" series. It provides structured exercises, templates, and activities for each module, allowing you to apply concepts immediately and build your professional portfolio as you learn.

**How to Use This Workbook:**
1. Read the corresponding module content
2. Complete the exercises in this workbook
3. Save your work to build your portfolio
4. Review answers against the Answer Key in Appendix F

### Exercise 14.3 – SQL Queries (Sample Answers)

**1. Average patient satisfaction by clinic:**
```sql
SELECT 
    c.clinic_name,
    AVG(ps.satisfaction_score) as avg_score,
    COUNT(ps.survey_id) as survey_count
FROM patient_surveys ps
JOIN clinics c ON ps.clinic_id = c.clinic_id
WHERE ps.survey_date >= '2024-01-01'
GROUP BY c.clinic_name
ORDER BY avg_score DESC;
```

**2. No-show rate by provider:**
```sql
SELECT 
    provider_id,
    COUNT(*) as total,
    SUM(CASE WHEN status = 'NO-SHOW' THEN 1 ELSE 0 END) as no_shows,
    ROUND((SUM(CASE WHEN status = 'NO-SHOW' THEN 1 ELSE 0 END) / COUNT(*)) * 100, 2) as no_show_pct
FROM appointments
WHERE date >= '2024-01-01'
GROUP BY provider_id
HAVING no_show_pct > 5
ORDER BY no_show_pct DESC;
```
