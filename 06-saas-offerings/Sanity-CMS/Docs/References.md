### Key Concepts from Official Docs

**Structured Content** is information broken into its smallest reasonable pieces, explicitly organized and classified to be understandable by computers and humans .

**Headless CMS** separates where content is stored (the "body") from where it is presented (the "head") .

**Composable** refers to the ability to assemble software, frameworks, products, and information to meet today's needs and easily evolve in the future .

## Quick Reference

### Key APIs

| API | Purpose |
|-----|---------|
| **Content Lake** | Store and query structured content  |
| **HTTP API** | Manage documents, assets, mutations  |
| **Live Content API** | Real-time event streaming  |
| **Webhooks** | Trigger actions on content changes |
| **Functions** | Serverless functions tied to content mutations  |
| **Agent Actions** | AI-powered content automation  |

### Key SDKs & Tools

- `@sanity/client` - JavaScript/TypeScript SDK 
- `@sanity/image-url` - Image URL builder
- `@portabletext/react` - Portable Text rendering
- `@sanity/vision` - GROQ query tool
- `sanity/cli` - Command-line interface

### Customization Approach

Sanity Studio is built from the ground up with customization in mind. You can customize :
- **Form Components** - Replace any input with custom React components
- **Structure Builder** - Organize document lists and navigation
- **Visual Elements** - Theming, icons, UI components
- **Tools & Plugins** - Add new sections and integrations
